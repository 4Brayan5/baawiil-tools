# Installer Baawiil Monitor

[Télécharger l’installateur Windows 11 x64](https://github.com/4Brayan5/baawiil-tools/raw/refs/heads/main/downloads/BaawiilMonitor-0.2.0-dev-setup.exe)

Version de développement 0.2.0, non signée. Les essais matériels et les critères de la version 1.0 restent à valider. [Couverture réelle](../docs/etat-implementation.md).

L’empreinte SHA-256 est fournie dans [SHA256SUMS.txt](SHA256SUMS.txt). Sous PowerShell :

```powershell
Get-FileHash .\BaawiilMonitor-0.2.0-dev-setup.exe -Algorithm SHA256
```
